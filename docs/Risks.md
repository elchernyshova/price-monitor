# Risks

## 1. Обзор

Документ описывает риски, которые могут возникнуть при работе системы мониторинга цен, и способы их митигации.

---

## 2. Таблица рисков

| ID | Риск | Вероятность | Влияние | Митигация |
|----|------|-------------|---------|-----------|
| R-01 | Капча на Vako.Market | Средняя | Высокое | Обнаружение, сохранение HTML, возврат ошибки |
| R-02 | Таймаут при запросе | Высокая | Среднее | Retry-логика (3 попытки) |
| R-03 | Изменение вёрстки Vako.Market | Средняя | Высокое | Гибкие XPath через `contains()` |
| R-04 | Блокировка IP | Низкая | Высокое | Принят. В текущей версии не обрабатывается |

---

## 3. Детализация критичных рисков

### R-01: Капча на Vako.Market

- **Что может произойти:** Vako.Market покажет капчу вместо страницы с товаром.
- **Причина:** защита от автоматических запросов.
- **Решение:** скрипт обнаруживает капчу, сохраняет HTML в файл `vako_captcha.html` и возвращает ошибку.
- **Результат:** ошибка фиксируется, HTML доступен для анализа.

### R-02: Таймаут при запросе

- **Что произошло:** при тестировании модель iPhone 17 256GB не спарсилась (3 таймаута подряд).
- **Причина:** сервер Vako.Market не отвечал в течение 15 секунд.
- **Решение:** реализована retry-логика (3 попытки с увеличивающейся задержкой).
- **Результат:** при повторном запуске модель успешно спарсилась.

### R-03: Изменение вёрстки Vako.Market

- **Что может произойти:** Vako.Market изменит HTML-структуру, и XPath перестанут находить элементы.
- **Причина:** обновление дизайна сайта.
- **Решение:** использовать гибкие XPath через `contains()` вместо точных классов.
- **Результат:** снижается риск поломки парсера.

### R-04: Блокировка IP

- **Что может произойти:** Vako.Market заблокирует IP-адрес за частые запросы.
- **Причина:** срабатывание защиты от ботов.
- **Решение:** риск принят. В текущей версии не обрабатывается.
- **Планы:** в V2.0 — использовать прокси-серверы.
