### UC-02: Собрать цены с Vako.Market

| Элемент | Значение |
|---------|----------|
| **Название** | Собрать цены с Vako.Market |
| **Контекст использования** | Владелец магазина хочет узнать актуальные цены конкурентов на 5 моделей iPhone для корректировки своей ценовой политики |
| **Область действия** | Система Price-Monitor |
| **Уровни** | Цель пользователя |
| **Основное действующее лицо** | Скрипт (Price-Monitor) |
| **Участники** | Скрипт, Vako.Market |
| **Предусловие** | Скрипт запущен, список моделей загружен |
| **Минимальные гарантии успеха** | При ошибке скрипт фиксирует проблему и завершает работу без сбоя |
| **Гарантии успеха** | Цены собраны со всех доступных моделей |
| **Триггер** | Скрипт запущен |
| **Описание основного сценария** | 1. Скрипт берёт URL модели из конфигурации.<br>2. Отправляет HTTP-запрос к Vako.Market.<br>3. Получает HTML-страницу.<br>4. Парсит цены, названия магазинов и ссылки.<br>5. Сохраняет данные для дальнейшей обработки. |
| **Расширения** | **3а. Таймаут при запросе:**<br>— Скрипт ждёт 2 сек, повторяет запрос (до 3 попыток).<br>— Если все попытки исчерпаны → фиксирует ошибку, переходит к следующей модели.<br>**3б. Обнаружена капча:**<br>— Скрипт сохраняет HTML в файл, возвращает ошибку. |
| **Изменения в технологии и данных** | Создаётся временная структура данных с ценами. При капче HTML сохраняется в файл `vako_captcha.html` для отладки |

### UC-03: Определить цвет модели

| Элемент | Значение |
|---------|----------|
| **Название** | Определить цвет модели |
| **Контекст использования** | Владелец хочет видеть цвета товаров для анализа популярных расцветок |
| **Область действия** | Система Price-Monitor |
| **Уровни** | Подфункция |
| **Основное действующее лицо** | Скрипт |
| **Участники** | Скрипт |
| **Предусловие** | Данные о ценах собраны |
| **Минимальные гарантии успеха** | Если цвет не найден — присваивается «Не указан» |
| **Гарантии успеха** | Цвет определён для всех товаров, где он указан |
| **Триггер** | Данные о ценах собраны |
| **Описание основного сценария** | 1. Скрипт берёт название модели.<br>2. Ищет ключевые слова цвета в словаре.<br>3. Возвращает цвет. |
| **Расширения** | **2а. Цвет не найден:** → присваивается «Не указан». |
| **Изменения в технологии и данных** | Добавляется поле «Цвет» в структуру данных |

### UC-05: Обработать ошибки сети (retry)

| Элемент | Значение |
|---------|----------|
| **Название** | Обработать ошибки сети (retry) |
| **Контекст использования** | Повторить запрос при временном сбое сети |
| **Область действия** | Система Price-Monitor |
| **Уровни** | Подфункция |
| **Основное действующее лицо** | Скрипт |
| **Участники** | Скрипт, Vako.Market |
| **Предусловие** | Запрос к Vako.Market не удался (таймаут, ошибка соединения) |
| **Минимальные гарантии успеха** | После 3 попыток фиксируется ошибка, скрипт продолжает работу |
| **Гарантии успеха** | Запрос выполнен успешно, данные получены |
| **Триггер** | Ошибка сети при запросе |
| **Описание основного сценария** | 1. Скрипт ждёт 2 сек.<br>2. Повторяет запрос.<br>3. До 3 попыток с увеличивающейся задержкой (2, 5, 8 сек). |
| **Расширения** | **3а. Все попытки исчерпаны:** → фиксируется ошибка, переход к следующей модели. |
| **Изменения в технологии и данных** | — |
