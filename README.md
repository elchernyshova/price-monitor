# Автоматизированная система мониторинга цен

## О проекте

Владелец небольшого магазина электроники тратит **до 2 часов в день** на ручной сбор цен конкурентов на самые популярные модели iPhone. Данный проект автоматизирует сбор и **приоритизирует** данные по цвету: скрипт собирает цены с агрегатора **Vako.Market** и формирует Excel-отчёт.

---

## Задача

| Проблема | Решение |
|----------|---------|
| Ручной сбор цен занимает до 2-х часов в день | Автоматический парсинг за 20 секунд |
| Реакция на изменения цен запаздывает | Ежедневный мониторинг по запросу |
| Нет данных для закупки | Приоритизация по цвету (1–3) |

---

## Результат

- **5 моделей** iPhone (топ-5 по продажам).
- **10+ магазинов** с Vako.Market.
- **50 записей** за один запуск (~20 секунд).
- Excel-отчёт с кликабельными ссылками.

## Стек технологий

| Технология | Назначение |
|------------|------------|
| Python 3.8+ | Язык разработки |
| requests | HTTP-запросы к Vako.Market |

## Как запустить

1. Установите зависимости:
   ```bash
   pip install requests lxml openpyxl
   ```

2. Запустите скрипт:
   ```bash
   python src/vako_parser.py
   ```

3. Откройте созданный Excel-файл в папке проекта.
