# Data Model

## 1. Обзор

Модель данных отражает структуру Excel-отчёта системы мониторинга цен.

**Источник данных:** агрегатор Vako.Market.
**Формат вывода:** Excel (.xlsx).

---

## 2. Структура Excel-отчёта

| Столбец | Тип | Источник | Обязательный | Описание |
|---------|-----|----------|--------------|----------|
| Товар | string | Конфигурация | Да | Модель iPhone |
| Цвет | string | Vako.Market | Да | Цвет товара |
| Приоритет цвета | int | Бизнес-логика | Да | 1–3, определяет важность цвета |
| Магазин | string | Vako.Market | Да | Название продавца |
| Цена (руб) | int | Vako.Market | Да | Цена в рублях |
| Ссылка | url | Vako.Market | Нет | Ссылка на товар |
| Дата | datetime | Автоматически | Да | Время сбора |

---

## 3. Словарь данных

| Столбец | Тип | Описание | Пример |
|---------|-----|----------|--------|
| Товар | string | Название модели iPhone из конфигурации | iPhone 17 Pro Max 256GB |
| Цвет | string | Цвет, извлечённый из названия с Vako.Market | Оранжевый |
| Приоритет цвета | int | 1 — хит, 2 — средний, 3 — второстепенный | 1 |
| Магазин | string | Название продавца с Vako.Market | FormulaTV.ru |
| Цена (руб) | int | Цена в рублях | 110799 |
| Ссылка | url | URL страницы товара у продавца | https://... |
| Дата | datetime | Дата и время сбора | 2026-09-10 19:30 |

## 5. Логика определения цвета

Система анализирует полное название модели, полученное с Vako.Market, и ищет в нём ключевые слова, соответствующие известным цветам. Словарь цветов включает:

- **Титан-варианты:** Natural Titanium, Desert Titanium, White Titanium, Black Titanium.
- **Цвета 17-й серии:** Cosmic Orange, Deep Blue, Mist Blue, Sage, Silver.
- **Универсальные:** Чёрный, Белый, Золотой, Розовый, Фиолетовый.

Если цвет не найден — присваивается значение «Не указан».

---

## 6. Ограничения модели

| Ограничение | Причина |
|-------------|---------|
| Цена не разделяется по цветам | На Vako.Market цена одна для всех цветов модели |
| Нет данных о наличии | Vako.Market не отдаёт информацию о наличии в этом формате |
| Цвет определяется по ключевым словам | Цвет извлекается из текста названия модели |
