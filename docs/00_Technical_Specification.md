## 2. Цели и назначение системы

### 2.1. Цели создания системы

| № | Цель | Критерий достижения |
|---|------|---------------------|
| 1 | Сократить время сбора цен на самые популярные модели среди конкурентов | С 2 часов до 2 минут |
| 2 | Обеспечить возможность ежедневного мониторинга цен | Отчёт формируется за ≤2 минуты |
| 3 | Обеспечить приоритизацию по цвету для закупки | Для каждой модели определён приоритет цвета (1–3) |
| 4 | Обеспечить быстрый доступ к товарам конкурентов | Кликабельные ссылки в Excel-отчёте |

### 2.2. Назначение системы

Система предназначена для автоматизации процесса мониторинга цен на самые популярные модели iPhone. Автоматизируемый вид деятельности — **сбор и анализ рыночных данных для принятия решений о закупке**.

## 3. Характеристика объекта автоматизации

### 3.1. Основные сведения об объекте

**Объект автоматизации:** процесс мониторинга цен на iPhone у конкурентов.

**Текущий процесс (до автоматизации):**
1. Владелец вручную открывает сайты магазинов.
2. Ищет нужные модели.
3. Записывает цены в Excel.
4. Анализирует данные.

**Проблемы текущего процесса:**
- Владелец тратит до 2 часов в день на ручной сбор цен.
- Реакция на изменения цен конкурентов запаздывает.
- Нет данных для принятия решений о закупке (какие цвета популярны, что закупать в первую очередь).

### 3.2. Условия эксплуатации

| Параметр | Значение |
|----------|----------|
| **Среда эксплуатации** | Локальный компьютер пользователя |
| **Операционная система** | Windows / macOS / Linux |
| **Требуемое ПО** | Python 3.8+, библиотеки requests, lxml, openpyxl |
| **Интернет-соединение** | Требуется |

## 6. Порядок разработки

| № | Этап | Срок | Ответственный | Комментарий |
|---|------|------|---------------|-------------|
| 1 | Анализ требований | День 1-2 | Системный аналитик | Интервью с заказчиком, определение моделей |
| 2 | Проектирование | День 3 | Системный аналитик | Модель данных, XPath, логика приоритетов |

## 7. Порядок контроля и приёмки

### 7.1. Виды испытаний

| Вид | Что проверяем |
|-----|---------------|
| Функциональное тестирование | Сбор цен, определение цвета, формирование Excel |
| Тестирование ошибок | Таймаут, недоступность источника |
| Проверка производительности | Время выполнения ≤ 2 минут |

### 7.2. Критерии приёмки

**Обоснование количества моделей:**
Мониторинг охватывает 5 популярных моделей iPhone. Все XPath проверены на корректность. Для приёмки критически важно, чтобы система собирала данные по всем 5 моделям.

- [ ] Скрипт собирает цены со всех 5 моделей
- [ ] В отчёте есть колонки: Товар, Цвет, Приоритет цвета, Магазин, Цена, Ссылка
- [ ] Цены заполнены (не «—») для всех найденных моделей
- [ ] Цвет определён там, где он указан на Vako.Market
- [ ] Приоритет цвета присвоен для всех товаров
- [ ] Ссылки кликабельны и ведут на Vako.Market
- [ ] Отчёт сохранён в формате .xlsx
- [ ] Время выполнения ≤ 2 минут
